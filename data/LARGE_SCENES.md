# Large scenes (300k – 3M bodies) — GPU astrophysics

These are the big-N systems GPU N-body codes are built for. They're generated by
`gen_large_scenes.py` (numpy, scales to millions), so you make whatever size you want
rather than shipping giant files. Load one, then press **U** (GPU direct, exact, great to
~100k–300k) or **B** (GPU Barnes-Hut, O(N log N), for the really big ones).

    python gen_large_scenes.py <scenario> <N> <out.csv>

| scenario | what it models | dynamics you'll see |
|---|---|---|
| `spiral_galaxy` | exponential disk + bulge + dark halo, rotation-supported | spiral arms / a bar wind up in the disk |
| `galaxy_merger` | two disk galaxies on a collision orbit | tidal bridges & tails, then a merger remnant (Antennae-style) |
| `cosmic_web` | cold, clumpy box | gravitational collapse into filaments, sheets and halos (structure formation) |
| `galaxy_cluster` | many galaxy-sized halos in a cluster potential | galaxies orbiting, harassing, and merging in a bound cluster |
| `colliding_clusters` | two galaxy clusters on a head-on orbit | cluster–cluster collision / pass-through (Bullet-cluster-style) |

## Ready-made examples

Provided alongside this project (generate the rest yourself):

    spiral_galaxy_300k.csv      300k    a live disk galaxy
    galaxy_merger_600k.csv      600k    two galaxies colliding
    cosmic_web_1M.csv           1M      structure formation
    galaxy_cluster_1M.csv       1M      a cluster of galaxies

## Making the big ones (fast, a few seconds to ~a minute)

    python gen_large_scenes.py spiral_galaxy       500000 disk500k.csv
    python gen_large_scenes.py galaxy_merger      1000000 merger1m.csv
    python gen_large_scenes.py cosmic_web         2000000 web2m.csv
    python gen_large_scenes.py colliding_clusters 2000000 bullet2m.csv
    python gen_large_scenes.py cosmic_web         3000000 web3m.csv

A 3M-body CSV is ~250 MB on disk, so they aren't shipped pre-built — the generator is the
deliverable. Memory: generating 3M needs ~1.5 GB RAM.

## Notes

- Each scene sets a **low `timescale`** in its header so it opens at a high framerate; press
  `+` to speed the evolution up once you're happy with the view.
- Physics is validated: at N=4000 every scenario conserves energy to ~1e-9–1e-10 over 300
  steps with no blow-ups; the large files parse and integrate cleanly. These are
  visualiser-grade equilibria, not research initial conditions (no cosmological power
  spectrum, single mass component per body).
- Colours encode structure (disk warm→cool by radius, bulge gold, halo dim blue; clusters by
  sub-halo).
